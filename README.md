# Swing Scanner

สแกนหุ้นด้วยเทคนิค Buy the Pullback in an Uptrend ดึงราคาจาก Yahoo Finance อัตโนมัติ
แล้วบอกว่าตัวไหนพร้อมเข้า พร้อม stop loss, เป้า, R:R และขนาดไม้

## เริ่มใช้งาน

1. ติดตั้ง Python 3.11 ขึ้นไปจาก https://www.python.org/downloads/ (ติ๊ก **Add python.exe to PATH**)
2. ดับเบิลคลิก `run.bat` ครั้งแรกจะติดตั้งไลบรารีราว 2–3 นาที
3. เบราว์เซอร์จะเปิดหน้า http://localhost:8501 เอง

## ไฟล์ในโฟลเดอร์

| ไฟล์ | ใช้ทำอะไร |
|---|---|
| `run.bat` | เปิดแอป |
| `app.py` | หน้าจอ Streamlit |
| `engine.py` | ดึงข้อมูล คำนวณ EMA/RSI/ATR สัญญาณ และแผนการเทรด |
| `watchlist.csv` | รายชื่อหุ้น (แก้ในแอปที่แท็บ "รายชื่อหุ้น" ได้) |
| `settings.json` | ค่าพอร์ตและกฎ (สร้างเมื่อกด "บันทึกค่า") |
| `fundamentals_manual.csv` | เกณฑ์ 5 ที่กรอกเอง |
| `notify.py` | สแกนครั้งเดียวแล้วพิมพ์สรุป / ส่ง Slack ถ้าตั้ง `SLACK_WEBHOOK_URL` |

## รหัสหุ้น

- หุ้นไทย: ชื่อย่อ + `.BK` เช่น `PTT.BK`
- DR: ใช้รหัสหุ้นต้นทาง เช่น `NVDA`, `0700.HK` (Tencent), `300750.SZ` (CATL)
  ราคา stop/เป้าจะเป็นสกุลเงินต้นทาง ให้ใช้ % ไปคำนวณกับราคา DR

ผลสแกนเป็นเครื่องมือช่วยตามกฎที่ตั้งไว้ ไม่ใช่คำแนะนำการลงทุน
